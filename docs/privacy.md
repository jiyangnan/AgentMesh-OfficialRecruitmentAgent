# 隐私与操作边界

- 原始简历文件、正文、文件名和本机路径留在用户本机。
- 产品服务只接收现有产品协议明确允许的结构化业务状态。
- 云端工作台“待补资料”表单中的草稿只留在浏览器；提交后答案直接交给本机 CLI，用户
  确认后只保存在本机资料库，不经过产品答案 API。
- Chrome 扩展只按当前填写任务读取必要字段，不能读取或上传整份本机资料库。
- 招聘网站 Cookie、密码和登录态留在浏览器中。
- Chrome 扩展不绕过 CAPTCHA，不自动勾选声明，不自动上传附件，不自动提交申请。
- 对未知或敏感的个人事实，工作台必须明确向用户提问并等待本机确认；声明、附件、
  CAPTCHA 和最终提交仍必须由用户处理。
- 不得把 API Key、真实个人资料、招聘数据或网页原文提交到本仓库。
