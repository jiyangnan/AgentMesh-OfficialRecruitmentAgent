AgentMesh360 · Chrome 扩展安装

根据你的网络条件，选择合适的官方安装方式。

官方 ZIP 0.6.7 现已可用，所有用户都可以从 AgentMesh360 工作台直接下载；Chrome Web Store 版本仍在审核，审核通过后可作为自动更新渠道。

下载官方 ZIP 查看商店安装

共同前置条件

  1. 先接入本机 Agent。macOS 或 Linux 使用官网的 curl ... install-agent.sh | sh 命令；Windows PowerShell 使用 powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://recruit.agentmesh360.com/install-agent.ps1 | iex"。
  2. 本机连接组件会随 CLI 一起注册。无论使用商店还是 ZIP，扩展都只需点击“连接本机 Agent”，不会要求再次寻找、复制或粘贴 API Key。

方式一：立即下载官方 ZIP 0.6.7

当前已经可用，适合所有用户；macOS、Windows 和 Linux 使用同一份扩展 ZIP。

下载官方扩展 ZIP 查看版本与 SHA-256
  1. 下载并解压。把 ZIP 解压到一个固定文件夹，不要直接选择 ZIP，也不要之后随意移动或删除该文件夹。
  2. 打开扩展管理页。在 Chrome 地址栏输入 chrome://extensions/。
  3. 开启开发者模式。打开扩展管理页右上角的“开发者模式”开关。
  4. 加载扩展。点击“加载已解压的扩展程序”。
  5. 选择解压目录。该目录必须直接包含 manifest.json、popup.html 和 executor.js。不要选择它外面多一层的父目录。
  6. 固定到工具栏。点击 Chrome 工具栏的扩展图标，把“AgentMesh-OfficialRecruitment”固定到工具栏。
  7. 连接本机 Agent。打开扩展并点击“连接本机 Agent”。扩展不会要求输入 API Key 或配对码。
  8. 打开真实报名页面。你不需要先回 Web 创建任务。自行打开并登录目标招聘官网，进入当前可见的报名步骤，再点击扩展中的“识别当前步骤”。
需要自动修复时交给 Agent。也可以让本机 Agent 运行 ora-workbench extension prepare，它会校验官方版本并准备固定目录；误删或损坏后运行 ora-workbench extension repair。

方式二：Chrome Web Store（审核中）

适合能够访问 Chrome Web Store 并希望由 Chrome 自动更新的用户。商店版本审核通过后，工作台会开放正式入口。

当前状态：商店审核中。审核完成前请使用上方已经发布的官方 ZIP。工作台不会把尚未公开的商店页面伪装成可用入口。

安装后如何确认

扩展管理页

卡片中应显示“AgentMesh-OfficialRecruitment”，并且开关处于启用状态。

Chrome 工具栏

点击已固定的扩展图标，应能看到“连接本机 Agent”或“识别当前步骤”，而不是 API Key、配对码输入框、“扩展已损坏”或文件缺失。

收到新版后如何升级

  1. Chrome 商店安装的用户由 Chrome 自动更新，无需重新加载目录。
  2. ZIP 安装用户先退出正在进行的辅助填写，让 Agent 运行 ora-workbench extension update。
  3. Agent 校验新版本并更新同一个固定目录；随后打开 chrome://extensions/，在扩展卡片上点击“重新加载”。
  4. 重新打开扩展，确认版本为 0.6.7 或更高，且本机 Agent 连接仍可恢复。

常见问题

Chrome 提示找不到 manifest.json

通常是选择了 ZIP、选择了解压目录外面多一层的父目录，或者 ZIP 没有完整解压。请进入目录确认能够直接看到 manifest.json，再重新加载。

重启 Chrome 后扩展不见了

先检查原解压目录是否被移动、改名或删除，再到扩展管理页确认扩展仍然启用。

Agent 提示扩展需要修复

运行 ora-workbench extension repair。CLI 会重新下载并校验官方 ZIP，修复同一个固定目录；完成后在扩展管理页点击“重新加载”。

为什么会看到开发者模式提示？

这是 Chrome 对手动加载 ZIP 解压目录的正常提示。能够访问 Chrome Web Store 的用户在商店版本审核通过后可改用商店安装，不需要开发者模式。

为什么不需要 API Key 或配对码？

扩展只在首次使用时连接本机 Agent，由本机 Agent 完成账户校验。之后每次从当前招聘页面代建短期会话，并把申请和填写证据同步到 Web；通用 API Key 不进入扩展。商店版与 ZIP 版都遵守同一边界。

扩展提示需要先导入标准简历

请让本机 Agent 读取你明确指定的标准简历并提交档案提案，再到 Web 工作台确认。扩展不会把招聘页面上的筛选项或表单选项当成你的个人档案。

扩展会替我提交申请吗？

不会。附件、验证码、声明、下一步和最终提交仍由你本人完成。

安装完成

打开一个真实招聘页面并使用扩展；完成识别或填写后，再到 AgentMesh-OfficialRecruitment 工作台 查看自动建立的申请和证据。
