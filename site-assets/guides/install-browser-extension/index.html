Early Access · Chrome 扩展安装

五分钟完成开发者模式安装。

当前种子用户版本暂不通过 Chrome Web Store 分发。请只从 AgentMesh360 官方产品域名下载扩展，并按照下面的顺序操作。

下载扩展 ZIP 查看安装步骤

首次安装

  1. 下载并解压。把 ZIP 解压到一个不会随手删除或移动的固定目录，例如“文稿/AgentMesh360/OfficialRecruitment 扩展”。
  2. 打开扩展管理页。在 Chrome 地址栏输入 chrome://extensions/ 并按回车。
  3. 开启开发者模式。打开扩展管理页右上角的“开发者模式”开关。
  4. 加载扩展。点击“加载已解压的扩展程序”。
  5. 选择正确目录。选择解压后直接包含 manifest.json、popup.html 和 executor.js 的目录。不要选择 ZIP，也不要选择它外面多一层的父目录。
  6. 固定到工具栏。点击 Chrome 工具栏的扩展图标，把“AgentMesh360 官网申请填写器”固定到工具栏。
  7. 首次连接三端工作区。打开扩展，工作台地址保持 https://recruit.agentmesh360.com，输入与本机 Agent 相同的 AgentMesh360 API Key，点击“连接三端工作区”。
  8. 打开真实报名页面。你不需要先回 Web 创建任务。自行打开并登录目标招聘官网，进入当前可见的报名步骤，再点击扩展中的“识别当前步骤”。
请保留解压目录。Chrome 开发者模式会直接读取这个目录。安装后删除或移动目录，扩展将无法继续加载。

安装后如何确认

扩展管理页

卡片中应显示“AgentMesh360 官网申请填写器”，并且开关处于启用状态。

Chrome 工具栏

点击已固定的扩展图标，应能看到“连接三端工作区”或“识别当前步骤”，而不是配对码输入框、“扩展已损坏”或文件缺失。

收到新版后如何升级

  1. 从本页重新下载官方 ZIP。
  2. 退出正在进行的辅助填写，解压并覆盖原扩展目录。
  3. 重新打开 chrome://extensions/。
  4. 在扩展卡片上点击“重新加载”。
  5. 重新打开扩展，确认版本为 0.4.0 或更高，且已有连接仍可恢复；若连接被清理，再输入一次通用 API Key。

常见问题

Chrome 提示找不到 manifest.json

通常是选择了 ZIP、选择了解压目录外面多一层的父目录，或者 ZIP 没有完整解压。请进入目录确认能够直接看到 manifest.json，再重新加载。

重启 Chrome 后扩展不见了

先检查原解压目录是否被移动、改名或删除，再到扩展管理页确认扩展仍然启用。

为什么会看到开发者模式提示？

这是 Chrome 对手动加载扩展的正常提示。当前 Early Access 采用这种方式服务少量种子用户，稳定规模化后再评估 Chrome Web Store。

为什么不再需要配对码？

新版扩展只在首次使用时连接同一 AgentMesh360 账户。之后每次从当前招聘页面自动创建 15 分钟短期会话，并把申请和填写证据同步到 Web。

扩展提示需要先导入标准简历

请让本机 Agent 读取你明确指定的标准简历并提交档案提案，再到 Web 工作台确认。扩展不会把招聘页面上的筛选项或表单选项当成你的个人档案。

扩展会替我提交申请吗？

不会。附件、验证码、声明、下一步和最终提交仍由你本人完成。

安装完成

打开一个真实招聘页面并使用扩展；完成识别或填写后，再到 AgentMesh-OfficialRecruitment 工作台 查看自动建立的申请和证据。
