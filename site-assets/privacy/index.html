隐私政策

只为你明确发起的官网申请辅助处理必要数据。

生效日期：2026 年 8 月 11 日。本文适用于 AgentMesh-OfficialRecruitment Web 工作台、Chrome 扩展、Skill 与 CLI 适配器。

我们提供什么

本产品帮助用户管理官网招聘来源、机会、申请进度，并在用户主动点击扩展后识别、预览和辅助填写当前招聘页面。扩展不会自行浏览招聘网站，也不会替用户完成验证码、声明、附件上传、下一步或最终提交。

处理的数据

  • 账户与权益：AgentMesh360 账户标识、登录状态、产品准入、订阅和 credits 状态。
  • 工作台数据：用户保存的来源、机会、申请、截止时间、状态、下一步动作、证据和已经确认的结构化档案版本。
  • 当前网页元数据：仅在用户主动点击扩展后处理当前活动页的 URL、标题、字段标签、控件类型、候选选项、格式约束、表单指纹和执行结果。我们不上传招聘网站 Cookie、密码或完整登录会话。
  • 本机私密资料：API Key、原始简历文件、用户在待补资料表单中提交的补充敏感答案和本机配对秘密保存在用户自己的设备，不进入浏览器扩展存储，也不由产品云端保存答案正文。
  • 产品访问统计：我们使用部署在 AgentMesh360 自有域名上的 Umami 了解页面可用性和内容使用情况，只记录不含查询参数的页面路径、来源页面及浏览器和设备概况；不发送账户邮箱、API Key、简历或档案内容、申请内容、网页表单值及招聘网站登录信息。

用途与共享

上述数据只用于身份与权益校验、生成可审阅的字段映射、执行用户确认的可逆填写、同步申请证据、维护进度、改进公开页面和排查产品故障。访问统计由 AgentMesh360 自行托管，不用于第三方广告。我们不出售个人数据，也不会向招聘网站之外的第三方代替用户提交申请。

本机与云端边界

Chrome 扩展通过只允许固定官方扩展身份调用的本机连接组件与用户自己的 Agent 协作。通用 API Key 和本机配对秘密不会返回扩展。动态待补资料由浏览器直接交给本机 Agent，并保存在本机资料库；云端只记录不含答案正文的任务状态和不可逆摘要。

保留、删除与安全

工作台数据按照账户提供持续申请管理。用户可以在工作台“数据管理”中查看各类具体记录，在删除预览中核对关联影响后逐条选择删除；也可以让自己的宿主 Agent 通过同一套精确记录预览与确认机制执行。删除工作台数据不会删除 AgentMesh360 账户、通行证或 credits 账本，也不会自动发起退款。为处理网络重试和防止重复执行，我们最多保留 30 天不含账户编号、简历字段、链接或申请内容的最小删除回执。本机数据由用户和本机 Agent 控制，可在本机单独移除。我们使用最小权限、来源校验、短时令牌、可撤销本机会话、传输加密和日志脱敏降低风险，但任何网络服务都无法承诺绝对安全。

联系我们
